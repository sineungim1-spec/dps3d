# DPS3D — 반도체 장비 정밀부품 품질검사 (자동+수동)

전교생 투어용 20~30초 자동 반복 시연 + 방문 학생용 1~2분 직접 체험을 한 화면으로 통합했습니다.

## 실행

`index.html`을 크롬 또는 엣지에서 열거나 GitHub Pages에 공개하세요. HTML 파일 한 개로 동작하며 서버, 카메라, 외부 API가 필요하지 않습니다.

## 2개 모드

- **자동 시연(기본)**: 가상 반도체 장비 정밀 그리퍼가 움직이며 검사/배출/통과가 반복됩니다. 방문 투어에 적합합니다.
- **직접 체험**: 버튼으로 정상/미세 불량/큰 불량 부품을 투입하고 이상점수 판정 기준(35~85점)을 바꿀 수 있습니다. 실제 부품 상태와 모의 판정 결과를 비교하며 오검출·미검출을 학습합니다. 60초 동안 조작이 없으면 자동 시연으로 돌아갑니다.

## 30초 안내 멘트

> 반도체 장비에도 정밀한 기계설계 부품이 필요합니다. 이 화면은 부품을 검사하고 분류하는 가상 생산라인입니다. 학생들은 기준을 조절하며 불량품을 잘 찾는지 직접 확인할 수 있습니다.

## 중요한 정확성 안내

**실제 카메라 AI가 학습·추론한 결과가 아닙니다.** 미리 정의한 부품별 이상점수를 기준으로 통과/배출을 결정하는 **교육용 규칙 기반 가상 시뮬레이션**입니다. 반도체 웨이퍼 이송용 기계부품은 개념을 전달하기 위해 단순화한 일러스트입니다.

수동 모드 점수 예시: 정상(46/35/26), 미세 불량(67/59/53), 큰 불량(92/84/97). 기준을 너무 낮추면 정상 오검출, 높이면 불량 놓침이 나타날 수 있습니다. 점수는 실제 장비 측정치가 아닙니다.
