# DPS3D — 반도체 장비 정밀부품 AI 검사 시뮬레이터

**3D융합설계과(AI융합설계과) 전교생 투어용 자동 반복 재생 웹 시연**입니다.

## 무엇을 보여주나요?
- 반도체 웨이퍼를 옮기는 로봇에 사용하는 **정밀 그리퍼(엔드이펙터) 부품**을 단순화해 시각화합니다.
- 부품이 컨베이어 위에서 움직이고, 검사 영역에서 정상/불량을 **모의 판정**한 뒤 자동 분리되는 장면을 보여줍니다.
- 기계제도·기계요소설계(CAD) → 제품 제작(3D프린팅/레이저가공) → 데이터 분석·AI 모델링의 기초 과정을 연결하여 소개합니다.

## 실행 방법
- [index.html](./index.html)을 내려받아 Chrome/Edge에서 엽니다.
- 설치 없이 브라우저에서 작동합니다. 전체화면, 속도 변경, 일시정지가 가능합니다.
- GitHub Pages를 켜면 온라인 URL로도 열 수 있습니다: Settings → Pages → Deploy from a branch → main / (root).

## 꼭 안내할 사항
**실제 AI 학습 모델의 판정 결과가 아닙니다.** 사전에 설정한 가상 검사 데이터를 이용한 **원리 설명용 시뮬레이션**입니다.
웨이퍼, 엔드이펙터와 자동 검사라인은 교육용 단순화된 그림으로, 실제 반도체 제조장비와 정확히 동일한 설계도는 아닙니다.

## 수정할 파일
- `index.html`: 화면 문구·색상·Canvas 장비와 부품 그림·검사 애니메이션 전체
- `README.md`: 실행·시연 설명
